## Files

```
index.html       Home page + "How Our Year Went" (one section per member)
team.html        Team cards with webpage + LinkedIn links
css/style.css    Shared styles
js/script.js     Read more / Read less button
images/          Photos (name yours like member2.jpg)
```

## What each member does

1. In `index.html`, find the section with your name  and fill it in.
   **Only edit inside your own section.**
2. In `team.html`, fill in your card and replace the two `#` links with your real links 
3. Add your photo to `images/` with the name used in your section (e.g. `member2.jpg`).

## How we use GitHub

Don't push directly to `main`. Work on your own branch and open a Pull Request.

```bash
git checkout main
git pull
git checkout -b yourname
# ...make changes...
git add .
git commit -m "Fill in my section"
git push -u origin yourname
```

Then on GitHub click **Compare & pull request**. The leader reviews and merges.
